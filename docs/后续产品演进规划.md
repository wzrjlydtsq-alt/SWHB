### 左侧栏详细设计（项目导航树）

**宽度**: 固定 240px，可折叠至 48px（仅显示图标）

**层级结构**:
- **Level 0** - 项目根节点
  - 图标: 📁 文件夹图标
  - 字体: 14px Semibold
  - 背景: 悬停时 `rgba(255,255,255,0.05)`
  
- **Level 1** - 剧集/季
  - 缩进: 16px
  - 图标: 📺 或季数标识
  - 字体: 13px Medium
  - 颜色: `#E0E0E0`
  
- **Level 2** - 集
  - 缩进: 32px
  - 图标: 🎬
  - 字体: 12px Regular
  - 颜色: `#BDBDBD`

- **Level 3** - 场景
  - 缩进: 48px
  - 图标: 🎭 (可拖拽)
  - 字体: 11px Regular
  - 颜色: `#9E9E9E`
  - **特殊状态**:
    - 当前选中: 左边框 2px 高亮色 + 背景 `rgba(66,133,244,0.15)`
    - 有修改未保存: 右侧显示橙色圆点 ●
    - 解析错误: 右侧显示红色警告 ⚠
    - 已锁定: 显示锁图标 🔒

**交互特性**:
- 支持拖拽排序场景
- 右键菜单: 新建场景、删除、重命名、复制、锁定
- 双击展开/收起子节点
- 搜索过滤功能 (Ctrl+F 聚焦到左侧栏)

### 中间编辑器详细设计（剧本编辑区）

**核心区域**:
- **字体**: 使用等宽字体以保持对齐
  - 主字体: `'JetBrains Mono', 'Fira Code', 'Consolas', monospace`
  - 字号: 14px (可缩放 12px-18px)
  - 行高: 1.8 (适合剧本阅读)

- **编辑器背景**: 
  - 主背景: `#1E1E1E` (深灰黑)
  - 当前行高亮: `rgba(255,255,255,0.03)`
  - 选中文字: `rgba(66,133,244,0.3)`

- **边距与留白**:
  - 左侧: 行号区域 (50px 宽，颜色 `#424242`)
  - 右侧: 折叠/大纲指示器 (20px)
  - 内容区域最大宽度: 720px 居中 (模拟标准剧本格式)
  - 上下 padding: 40px

**剧本元素格式化示例**:

```text
[行号]  INT. 咖啡厅 - 日                    ← 场景标题 (居中, 加粗)
       
       阳光透过落地窗洒在木质桌面上。          ← 动作描述 (左对齐)
       客人们低声交谈，咖啡机嗡嗡作响。
       
       李明                                  ← 角色名 (大写, 居中)
       (端起咖啡杯，若有所思)                 ← 括号动作 (括号内)
       你觉得这个方案可行吗？                   ← 对白 (居中, 稍缩进)
       
       张伟                                   ← 角色名
       我需要再考虑一下。                      ← 对白
       
       (O.S.)                                ← 画外音标识
       广播: 请注意，即将关门。                ← 旁白/画外音
       
       FADE TO BLACK.                        ← 转场 (全大写, 右对齐)
```

**底部状态栏**:
```
第 12 场 | 共 45 场 | 字数: 2,340 | 行 127, 列 18 | UTF-8 | 已保存 ✓ | AI解析完成
```

## 2. 颜色和高亮规则

### 主色调定义

| 用途 | 颜色值 | 说明 |
|------|--------|------|
| **背景主色** | `#1E1E1E` | 编辑器主背景 |
| **背景次要** | `#252526` | 侧边栏背景 |
| **背景三级** | `#2D2D30` | 面板/弹窗背景 |
| **前景主色** | `#D4D4D4` | 默认文字颜色 |
| **前景次要** | `#9CDCFE` | 次要信息文字 |
| **边框色** | `#3E3E42` | 分隔线、边框 |
| **高亮色** | `#4285F4` | 选中状态、链接 |
| **成功色** | `#4CAF50` | 保存成功、正常状态 |
| **警告色** | `#FF9800` | 待确认、未保存 |
| **错误色** | `#F44336` | 解析错误、冲突 |

### 剧本语法高亮规则

#### 场景标题 (Scene Heading)
```css
.scene-heading {
  color: #569CD6;        /* 浅蓝色 */
  font-weight: bold;
  font-size: 14px;
  text-transform: uppercase;
  text-align: center;
  background: rgba(86,156,214,0.08); /* 微弱背景 */
  border-bottom: 1px solid rgba(86,156,214,0.2);
  margin-top: 16px;
  padding: 6px 0;
}
/* 示例: INT. 咖啡厅 - 日 */
```

#### 角色名称 (Character Name)
```css
.character-name {
  color: #4EC9B0;        /* 青绿色 */
  font-weight: bold;
  font-size: 14px;
  text-transform: uppercase;
  text-align: center;
  margin-top: 12px;
  letter-spacing: 0.5px;
}
/* 示例: 李明 */
```

#### 对白内容 (Dialogue)
```css
.dialogue {
  color: #D4D4D4;        /* 默认白色 */
  font-size: 14px;
  text-align: center;
  padding-left: 25%;      /* 标准剧本缩进 */
  padding-right: 25%;
  line-height: 1.7;
}
/* 示例: 你觉得这个方案可行吗？ */
```

#### 动作描述 (Action/Description)
```css
.action-description {
  color: #CE9178;        /* 橙棕色 */
  font-size: 14px;
  text-align: left;
  line-height: 1.8;
  padding-left: 0;
}
/* 示例: 阳光透过落地窗洒在木质桌面上。 */
```

#### 括号动作 (Parenthetical)
```css
.parenthetical {
  color: #C586C0;        /* 紫色 */
  font-size: 12px;
  font-style: italic;
  text-align: center;
  padding-left: 20%;
  opacity: 0.85;
}
/* 示例: (端起咖啡杯，若有所思) */
```

#### 旁白/画外音 (Voice Over / Off Screen)
```css
.voice-over {
  color: #DCDCAA;        /* 浅黄色 */
  font-size: 13px;
  font-style: italic;
  opacity: 0.9;
  border-left: 2px solid rgba(220,220,170,0.4);
  padding-left: 10px;
}
/* 示例: (V.O.) 广播: 请注意... */
```

#### 转场标记 (Transition)
```css
.transition {
  color: #D16969;        /* 红色 */
  font-weight: bold;
  font-size: 13px;
  text-transform: uppercase;
  text-align: right;
  padding-right: 15%;
  letter-spacing: 1px;
}
/* 示例: FADE TO BLACK. */
/* 示例: CUT TO: */
```

#### 错误/待确认解析块
```css
.parse-error {
  background: rgba(244,67,54,0.12);  /* 红色半透明背景 */
  border-left: 3px solid #F44336;     /* 红色左边框 */
  color: #F44336;                     /* 红色文字 */
  padding: 8px 12px;
  margin: 8px 0;
  border-radius: 3px;
}

.parse-warning {
  background: rgba(255,152,0,0.12);  /* 橙色半透明背景 */
  border-left: 3px solid #FF9800;     /* 橙色左边框 */
  color: #FF9800;                     /* 橙色文字 */
  padding: 8px 12px;
  margin: 8px 0;
  border-radius: 3px;
}

.parse-unconfirmed {
  background: rgba(255,193,7,0.1);   /* 黄色半透明背景 */
  border: 1px dashed #FFC107;        /* 黄色虚线边框 */
  color: #FFC107;                     /* 黄色文字 */
  padding: 6px 10px;
  font-style: italic;
  opacity: 0.85;
}
```

### 特殊标记颜色

| 元素类型 | 颜色值 | 使用场景 |
|----------|--------|----------|
| **注释/备注** | `#6A9955` 绿色 | `/* 导演备注 */` 或 `[[批注]]` |
| **占位符** | `#606060` 灰色 | `[TODO: 补充对白]` |
| **AI生成内容** | `rgba(156,220,254,0.3)` 浅蓝底 | AI辅助生成文本的微弱背景 |
| **冲突标记** | `#E06C75` 粉红 | 角色性格矛盾、剧情逻辑问题 |
| **引用链接** | `#4FC1FF` 亮蓝 | 点击跳转到其他场景/人物 |
| **高亮搜索** | `#FFFF00` 黄底黑字 | 全局搜索匹配项 |


**局部解析状态** (编辑器内):
```text
[行号]  INT. 咖啡厅 - 日

       ████████████░░░░░░ 正在分析角色关系...
```

- 进度条: 使用渐变色 `linear-gradient(90deg, #4285F4, #4EC9B0)`

- 整体遮罩: `rgba(30,30,30,0.7)` + backdrop-filter blur(4px)

### 状态 3: 解析失败（错误状态）

**错误展示方式**:

```text
═══════════════════════════════════════════════
⚠️ 解析错误: 第 23-28 行格式无法识别
═══════════════════════════════════════════════

[错误代码块 - 红色边框高亮]
  23 | 李明
  24 | (突然站起来)  ← ❌ 缺少对白内容
  25 | 
  26 | 张伟
  27 | 等等，你还没说完呢！
  28 | 

[错误原因]
• 角色名后紧跟括号动作，但缺少实际对白文本
• 可能是误操作或复制粘贴导致的格式错误

[操作按钮]
[🔧 自动修复] [✏️ 手动编辑] [📋 忽略并继续] [❓ 查看帮助]

═══════════════════════════════════════════════
```

**视觉特征**:
- 错误区域: 红色左边框 3px + 半透明红背景
- 错误图标: ⚠️ (警告) 或 ❌ (严重错误)
- 错误行号: 在行号列用红色圆圈标注
- 波浪下划线: 类似 IDE 的拼写检查红线
- 右侧错误面板自动展开，列出所有错误列表


## 4. 给开发者的 UI 注意事项

### 4.1 性能优化 - 避免卡顿

#### 虚拟滚动 (Virtual Scrolling)
**问题**: 剧本可能长达数百页，DOM 节点过多导致卡顿

**解决方案**:
```javascript
// 推荐实现方案
{
  // 只渲染可视区域 + 缓冲区的行
  visibleRowCount: 50,        // 可视区域显示约 50 行
  bufferSize: 20,             // 上下各缓冲 20 行
  rowHeight: 28,              // 每行固定高度 (含行高)
  
  // 对于不同高度的元素 (如场景标题块)
  // 使用动态高度测量缓存
  estimatedRowHeight: 28,
  measureCache: new Map(),    // 缓存已测量的行高
}
```

**注意事项**:
- 场景标题、转场等特殊块可能占用多行，需要动态计算高度
- 语法高亮应在 Web Worker 中执行，避免阻塞主线程
- 搜索/替换操作应使用增量更新，而非重新渲染全文

#### 防抖与节流 (Debounce & Throttle)
```javascript
// 适用场景
{
  autoSave: {
    debounce: 2000,           // 停止输入 2 秒后自动保存
    maxWait: 10000            // 最长 10 秒必须保存一次
  },
  
  syntaxHighlight: {
    throttle: 100,            // 语法高亮最多每 100ms 更新一次
    useWorker: true           // 必须 Web Worker
  },
  
  treeViewScroll: {
    passive: true,            // 使用被动事件监听
    requestAnimationFrame: true // 滚动时使用 rAF
  },
  
  resizeObserver: {
    debounce: 150             // 窗口大小变化防抖
  }
}
```

#### 内存管理
- **大型文件处理**: 超过 500 行时分块加载
- **撤销栈限制**: 最多保留 100 步 undo 历史
- **图片资源**: 分镜图片使用懒加载 + 缓存策略 (LRU Cache)
- **定时清理**: 及时清理不再使用的 DOM 节点和事件监听器

### 4.2 布局适配 - 避免三栏过挤

#### 断点设计 (Breakpoints)

| 屏幕宽度 | 左侧栏 | 中间编辑器 | 右侧栏 | 备注 |
|----------|--------|------------|--------|------|
| **≥ 1600px** | 240px | flex | 320px | 完整三栏布局 |
| **1280-1599px** | 200px | flex | 280px | 略压缩 |
| **1024-1279px** | 48px (图标) | flex | 可折叠 | 左侧仅图标 |
| **< 1024px** | 隐藏 | 100% | 底部抽屉 | 单栏 + 抽屉 |

#### 自适应策略

**左右栏拖拽调整**:
```javascript
// 允许用户自定义栏宽
{
  minWidth: {
    left: 180,    // 左侧最小 180px
    right: 260,   // 右侧最小 260px
    editor: 600   // 编辑器最小 600px
  },
  
  defaultWidth: {
    left: 240,
    right: 320
  },
  
  // 记住用户的偏好设置
  persistToLocalStorage: true,
  key: 'workspace-layout-preferences'
}
```

**智能隐藏机制**:
```
当窗口宽度 < 1400px 时:
1. 右侧栏自动折叠 (可通过按钮临时展开)
2. 左侧栏切换为窄模式 (仅显示图标)
3. 编辑器获得更多空间

当窗口宽度 < 1100px 时:
1. 左右两侧完全隐藏
2. 通过浮动按钮触发侧边抽屉
3. 编辑器全屏显示
```

**内容优先级**:
- **必须常驻**: 中间编辑器 (核心工作区)
- **次要重要**: 左侧导航树 (可折叠为图标)
- **按需显示**: 右侧信息面板 (可完全隐藏)
