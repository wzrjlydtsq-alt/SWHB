## 1. Codex 接手任务

### Codex-C1：统一云端契约并修通最小闭环

状态：已完成代码对齐，真实数据库 smoke 已通过。

负责文件：

- `server/src/routes/writing.ts`
- `server/migrations/004_writing_studio.sql`
- `src/renderer/services/cloud/writingClient.ts`
- `src/renderer/services/cloud/writingTypes.ts`
- `src/renderer/features/writing/assignmentClient.ts`
- 必要时更新本文档和 `docs/写作工作台与剧集制素材库详细执行方案.md`

任务：

1. 修正前后端路由不一致。
   - 前端不要再调用不存在的 `/writing/assignments/received`、`/writing/assignments/sent`。
   - 统一使用后端已有接口，或补齐后端对应接口，但必须二选一。
   - `accept/submit` 的 HTTP 方法必须和后端一致。
   - 当前处理：前端统一使用 `/writing/assignments/me`；后端新增 `/writing/assignments/sent` 供导演视角查询；`accept/submit` 均为 `PATCH`。

2. 修正任务字段不一致。
   - 后端创建任务读取 `shot_id / text_asset_id / episode_id / assignee_id / title / description / deadline`。
   - 前端 cloud adapter 不能发送只有 `storyboard_shot_id / type / team_id` 的不兼容请求。
   - 本地 Mock 字段可以保留，但 cloud 转换必须显式映射。
   - 当前处理：cloud adapter 显式映射 `storyboardShotId -> shot_id`，且 cloud 模式拒绝本地 Mock 字符串 ID 静默转成 `0`。

3. 修正候选媒体查询字段。
   - `assets` 表当前字段是 `thumb_oss_key`，不是 `thumbnail_oss_key`。
   - 分镜候选媒体接口必须能真实查询。
   - 当前处理：后端查询和前端 DTO 均统一为 `thumb_oss_key`。

4. 建立最小 HTTP 契约验证。
   - 至少覆盖：创建项目、创建剧集、创建分镜、创建任务、接收任务、提交任务、绑定候选媒体、审核候选媒体。
   - 如果暂时不能连真实 MySQL，要写清楚原因，并提供可执行的 smoke 脚本草案。
   - 当前状态：已有 build/test 验证；ECS/RDS `smoke-writing.mjs` 已通过 36/36。

验收：

- `npm run build` 通过。
- `npm test -- --run` 通过。
- `npm --prefix server run build` 通过。
- `npm --prefix server test` 通过。
- cloud adapter 切到 `cloud` 时，不会因为路径、方法、字段名不一致直接 404/405/400。
