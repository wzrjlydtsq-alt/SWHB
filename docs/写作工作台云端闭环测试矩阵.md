# 写作工作台云端闭环测试矩阵

更新时间：2026-05-07

本测试矩阵用于验证“写作工作台 -> 分镜 -> 画布生成 -> 任务流转 -> 云端闭环”的全链路流程。

> **状态说明**：以下 1~6 节属于【能演示的本地链路】；第 7 节属于【真实云端 API 链路，已在 ECS/RDS 环境通过 smoke】。下一步是桌面端 UI 切 cloud adapter 做真实账号联调。

## 测试前置条件

- **环境准备**：启动前端应用（`npm run dev`）。
- **数据准备**：确保本地或云端存在测试用的团队（Team）、成员（Members）、和一部测试剧集（如“测试剧集 A”，包含第一集）。
- **角色设定**：需要两个账号（或 Mock 切换）：导演账号 A，组员账号 B。
