# 类 Codex 工作台对标查缺补漏

更新时间：2026-06-11

## 对标基准

参考 Codex app 的核心能力：多项目/多线程工作、项目目录权限、审批与沙箱、内置终端、浏览器预览与页面反馈、电脑操作、Skills/Plugins、自动化、Git/Review、任务侧栏、非代码素材预览。

## 当前差距与落地策略

1. 项目与线程
   - 已有：独立的工作台项目/文件存储，不污染画布和生产板；创建项目时选择本机文件夹，并作为该项目的授权目录/缓存根；空项目文件夹也保留在侧栏，顶部显示项目文件夹/文件/本机目录归属。
   - 已补：命令面板支持导出/导入工作台项目元数据，导出文件为 `xinghe-workspace-export.json`，用于迁移/备份项目文件夹、工作台文件、任务、审计、浏览器证据和审查记录。
   - 已补：项目文件夹支持重新绑定本机目录，目录移动/丢失后可修复 cacheRoot 与 allowedRoots。
   - 已补：导入后会批量检查项目绑定的本机目录，缺失目录会进入任务面板和审计记录，提醒用户重绑。
   - 已补：导入后检测到缺失目录时可立刻逐个选择新目录，自动同步项目文件夹、工作台文件 cacheRoot / allowedRoots，并写入任务和审计。

2. Composer
   - 已有：文本、图片、音频、视频、文件粘贴/拖拽，模型切换，权限入口；无路径的剪贴板媒体会保存到当前工作台项目缓存目录。
   - 已补：素材缓存失败会写入任务面板和操作审计，避免剪贴板/拖拽媒体落盘失败时静默丢失。
   - 已补：文本、代码、JSON、CSV、字幕、日志、配置等可读附件会生成摘要，并把有限长度文本预览带入助手上下文。
   - 已补：Word `.docx` 附件会抽取纯文本并进入有限长度上下文。
   - 已补：PDF、Excel、Word 和纯文本附件会抽取有限正文/表格预览进入工作台上下文；PDF 可在附件弹窗内嵌预览，Excel/Word/文本可查看可滚动正文预览。
   - 已补：PDF/Excel 超出当前抽取范围时会在附件摘要和 AI 上下文里标记“已截断”，解析失败会保留明确原因。
   - 待补：继续补更深的 PDF 版式结构、超大表格分页检索和加密文档回退提示。

3. 权限与审批
    - 已有：目录范围/全局电脑，读写删命令权限，请求批准/帮我批准/完全访问。
    - 已补：审批策略同时存在于输入框小弹层与设置页，可选请求批准/帮我批准/完全访问；右侧进度面板可展开操作审计，显示可读标签、目标路径和错误。
    - 已补：待批准操作会显示敏感原因，批准/拒绝审计会中文化并保留对应风险说明。
    - 已补：右侧进度面板新增待批准操作卡，可直接查看目标、风险原因并通过/拒绝，不必回到输入框权限弹层。
    - 已补：批准或拒绝操作后会写入任务面板，保留目标、命令、执行结果和 stdout/stderr 摘要。
    - 已补：审批偏好会保存到工作台文件，切换不同工作台文件时自动恢复对应的请求批准/帮我批准/完全访问。
    - 已补：项目文件夹可保存访问范围、授权目录、细粒度权限和审批偏好为默认值，新建工作台文件会继承，也可一键套用到当前项目文件。

4. 任务与进度
   - 已有：右侧进度/任务可收起面板；任务支持展开查看 Skill、自动化、浏览器和审查细节，状态已中文化。
   - 已补：自动化常用模板会创建工作台任务、写入审计，并把执行说明带回输入框继续推进。
   - 已补：右侧进度面板展示最近产物/素材，支持缩略图预览、复制路径、打开所在位置和引用回输入框。
   - 已补：最近产物会优先显示当前工作台文件素材，并聚合整个工作台其他项目/文件的素材来源；发送请求时也会把最近素材路径和来源带入工作台上下文。

5. 浏览器交互
    - 已有：浏览器目标记录、打开 URL、验证任务、HTTP/标题/截图/DOM/视口/会话证据，输入框 URL 控件可直接开启持久会话，右侧进度面板可回看最近浏览器证据、一键复查、打开预览会话、直接补截图/DOM 取证、展开最近历史、复制截图路径、关闭会话和清空记录。
    - 已补：工作台浏览器会话默认使用项目/工作台文件绑定的持久 profile，同一工作台可复用 cookie/localStorage 登录态，AI 上下文和证据卡会显示复用状态。
    - 已补：新增 Console 诊断工具，可收集页面 console 警告/错误、加载失败和渲染崩溃摘要，并回写浏览器证据卡；持久浏览器会话会持续记录日志，控制台诊断可读取当前会话而不重新加载页面。
    - 已补：支持用户授权导入外部浏览器 cookies JSON 到当前工作台持久浏览器 profile，UI、AI 工具、证据卡和审计记录都能回写结果。
    - 待补：直接读取 Chrome/Edge 加密 profile、完整失败回退链。

6. 电脑操作
    - 已有：文件读写、移动、删除、命令、终端会话底座。
    - 已补：写入、复制、移动、删除、命令、终端等敏感操作会展示可读原因，审批后的审计记录也能回看原因。
    - 已补：工作目录索引会进入助手请求上下文，包含已扫描目录/文件路径和文件大小，便于像 Codex 一样围绕本机目录协作。
    - 已补：进度面板会展示最近已批准、已拒绝和失败的操作结果，可复制执行结果用于回放。
    - 已补：审批弹窗、目录搜索和全局访问确认文案已压缩为短句。
    - 待补：继续根据实机反馈微调权限入口位置和默认模式。

7. Skills / Plugins
    - 已有：本地 Skill CRUD 与执行工具、插件页。
    - 已补：内置推荐技能、技能安装入口、Skill 可通过自动化面板执行；推荐技能安装、技能、预设、流水线、定时任务操作结果会回写到工作台任务和审计记录。
    - 已补：推荐 Skill 默认先读取工作台上下文，再执行浏览器验收、发布前检查或素材入库检查，减少用户重复交代当前项目状态。
    - 已补：插件页读取本地 Skill 库，展示已安装 Skill 数量、描述和可用状态，并提供直接管理入口。
    - 已补：插件页新增可持久化连接器管理，飞书、代码托管、Figma、本机浏览器和云素材库可启用/停用，状态写入任务/审计，并进入工作台 AI 上下文。
    - 待补：和真实插件包/外部连接器打通。

8. 自动化
   - 已有：自动化页和定时任务工具底座。
   - 已补：自动化浮窗主要用户可见文案已中文化，减少 Built-in/Custom/Run/steps 等工程化露出。
   - 已补：常用任务模板不再只是跳转入口，启用后会进入任务/进度体系并留下审计记录。
   - 已补：任务面板可创建飞书确认任务，写入任务/审计，并把手机端确认消息草稿带回输入框。
   - 已补：浏览器回归检查模板可创建页面验收任务草稿，覆盖 URL、DOM、截图、移动端视口和关键交互。
   - 已补：自动化页展示可筛选运行历史，可展开任务详情、复制结果，并把历史记录回填到对话框继续处理。
   - 已补：自动化页接入定时计划底座，可启用常用计划、查看运行次数和取消计划，并写入任务/审计。
   - 已补：自动化历史展开态展示步骤时间线，失败记录可生成带尝试次数、退避时间和下次重试时间的本地重试任务。
   - 已补：到期的失败重试任务会由本地执行器自动派发到工作台对话，更新执行中/完成/失败状态，并写入审计记录。
   - 待补：跨任务依赖回放和真实后台无界面执行。

8.1 飞书直连
   - 已有：FeishuBridge 主进程网关、设置页配置、生产板无人值守推送。
   - 已补：工作台飞书页可读取 FeishuBridge 状态、刷新群列表、测试连接，并向选定飞书群发送工作台测试消息。
   - 待补：手机端审批结果回写到具体工作台任务的完整联调。

9. Review / Git
   - 已有：基础终端和文件操作可承载；右侧进度面板可展示结构化审查卡片、文件风险、增删行统计、diff 片段、可复制审查报告和可复制 diff 片段。
   - 已补：审查结果会和同目录上一轮成功审查对比，展示新增改动文件、已消失改动文件、仍在改动文件和增删行变化，并写入可复制报告。
   - 已补：Diff 片段按文件解析为逐 hunk 展开视图，审查卡默认保持紧凑，并可一键展开全部 diff 文件和 hunk。
   - 已补：每个 hunk 可复制行内审查意见草稿，用于继续交给 AI 或人工处理。
   - 已补：新增 `post_github_pr_comment`，可通过用户本机已登录的 `gh` CLI 写回 GitHub PR 普通评论或行内评论，失败时把 gh/PR 参数错误写入审计。
   - 已补：右侧审查卡支持填写 PR 号，在具体 hunk 上展开可编辑行内评论草稿并直接回写 GitHub PR。
   - 已补：新增 `submit_github_pr_review`，可通过 `gh` CLI 一次性提交包含多条行内评论的 GitHub PR Review。
   - 已补：新增 `post_gitlab_mr_comment`，可通过用户本机已登录的 `glab` CLI 写回 GitLab MR note，并在有 path/line 时尝试行内 note。
   - 待补：GitLab Review 批量 discussion 提交和不同托管平台的 OAuth 授权管理。

10. UI 与交互一致性
    - 已有：三界面切换、类 Codex 暗色布局。
    - 已补：命令面板、Slash 快捷入口、任务化反馈、隐藏“Agent”概念入口。
    - 已补：回答后的消息流改为类 Codex 的用户气泡、助手正文、消息复制和附件预览布局。
    - 已补：长回答会根据 Markdown 标题生成可点击目录锚点，方便在工作台内快速跳转。
    - 已补：生成中状态可展开查看上下文整理、附件读取、权限检查、模型调用和结果写回步骤。
    - 已补：回答完成后会展示本轮工具操作记录，包含调用的工具、成功/失败状态和错误摘要。
    - 已补：最近本机操作结果会写入下一轮工作台请求上下文，便于 AI 接着回放处理。
    - 待补：继续打磨真实工具执行过程的逐步流式回放。
