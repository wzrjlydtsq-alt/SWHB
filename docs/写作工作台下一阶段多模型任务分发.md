# 写作工作台下一阶段多模型任务分发

更新时间：2026-05-07

目标：把“星河写作工作台 + 剧集制素材库”从本地 Mock 链路推进到真实云端协作链路。四个模型并行工作时必须分文件、分职责，避免互相覆盖。

通用要求：

- 不要改无关文件。
- 不要回滚别人已经完成的 W1-W12 本地 Mock 功能。
- 所有实现必须保留现有本地 Mock 路径，真实云端能力用可切换 client / adapter 接入。
- 所有新增接口、表、字段都要和现有 `server/`、`src/renderer/services/cloud/` 风格对齐。
- 交付前必须说明修改文件、验证命令、未完成风险。

   - `writing_projects`

   - `writing_text_assets`

   - `writing_story_elements`

验收：

- `server npm run build` 或项目内对应后端构建命令通过。
