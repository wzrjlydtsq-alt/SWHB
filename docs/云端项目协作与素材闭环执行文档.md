# 云端项目协作与素材闭环执行文档

> 目标：把“项目管理、写作台、画布、批量生产板、团队云素材库、收藏夹、云端管理后台”连成一条真实生产闭环。  
> 原则：云端负责项目、剧集、任务、权限、审核、素材索引；本地负责制作、缓存、编辑和临时归档；用户明确点击上传后，制作结果才进入云端素材库。

## 1. 核心判断

当前“项目管理里的文件夹”不应该只是本地文件夹。它需要和云端剧项目建立映射。

例如：

- 本地项目管理中创建文件夹：`率土之滨`
- 云端管理后台中存在剧项目：`率土之滨`
- 文件夹内本地项目：`第 1 集 / 第 2 集 / 第 3 集 / 第 4 集 / 第 5 集 / 第 6 集`
- 云端对应剧集：`Episode 1 / Episode 2 / ... / Episode 6`

这两层要绑定，但不能误解为“本地文件全都自动上云”。正确关系是：

- 文件夹和剧集结构来自云端同步。
- 剧本、镜头本、任务、素材索引来自云端同步。
- 画布节点、生成历史、本地缓存、临时文件仍保存在本地。
- 只有用户点击“上传云素材库 / 提交完成 / 同步草稿”等动作，内容才写回云端。

## 2. 角色与权限

### 2.0 角色体系总览

角色必须走显式 RBAC 权限模型，不能依赖前端隐藏按钮或写死判断。所有敏感权限必须由云端校验，前端只负责展示。

推荐角色：

| 角色 | 定位 | 权限范围 |
| --- | --- | --- |
| 平台管理员 | 系统级运维角色 | 管理企业、团队、账号、套餐、全局配置、系统审计 |
| 企业管理员 | 企业级管理角色 | 管理本企业团队、成员、项目、权限、素材空间 |
| 管理员 | 团队级管理角色 | 管理团队成员、剧项目、任务分发、团队素材库 |
| 总导演 | 创作总负责人 | 管理全部剧项目、剧集、剧本审核、视觉资产审核、制作审核 |
| 导演 | 单剧或多剧负责人 | 管理被授权剧项目、剧集、任务和审核 |
| 编剧 | 写作生产角色 | 撰写剧本、同步草稿、提交剧本、查看被授权剧集 |
| 组员 | 制作生产角色 | 查看任务、制作素材、上传未审核资产、提交完成 |
| 访客/查看者 | 只读角色 | 只读查看被授权内容 |
| 紧急管理员 | 可审计救援角色 | 仅用于系统救援，拥有高权限，但必须显式存在、强审计、可禁用 |

不允许实现“隐藏角色、隐藏账号、不可发现的超级权限、写死账号密码”。如果确实需要最高权限入口，必须使用“紧急管理员”方案：

- 账号由企业管理员或平台管理员显式创建。
- 密码必须由用户首次登录后修改。
- 必须支持双因素校验或一次性登录码。
- 每次登录、查看、修改、删除、审核、导出都写入审计日志。
- 后台必须能看到该账号存在。
- 可一键禁用。
- 仅在系统救援、迁移、权限误删、客户授权排障时使用。

### 2.0.2 权限实现要求

- 后端所有接口必须校验 `userId/teamId/projectId/episodeId/role/permission`。
- 前端隐藏按钮不等于权限控制。
- 所有删除、审核、成员变更、权限变更、批量导出必须写审计日志。
- 管理员和总导演可以是角色，也可以是用户在某个项目下的成员身份。
- 一个用户可以同时拥有多个角色，但后端返回时必须明确权限来源。
- 任务权限以“分配”为准，不能因为用户在同团队就看到所有剧集细节。
- 紧急管理员默认禁用，由平台管理员在后台开启，开启必须填写原因。

### 2.1 导演

导演在星河云端管理后台创建剧项目、剧集、任务和审核规则。

导演可以：

- 创建剧项目。
- 创建剧集。
- 指派编剧写剧本。
- 审核剧本。
- 确定视觉资产方向，包括角色、场景、道具、参考视频。
- 指派组员制作图片、视频、音频或补充资产。
- 审核组员上传的单集资产。
- 标记单集完成。

### 2.2 编剧

编剧登录写作台后，自动看到被分配的剧项目和剧集。

编剧可以：

- 打开云端同步来的剧项目。
- 撰写每一集剧本。
- 保存本地草稿。
- 同步云端草稿。
- 提交给导演审核。
- 根据导演反馈修改。
- 剧本通过后，继续生成或整理镜头本草案。

### 2.3 组员

组员登录账号后，项目管理会出现云同步文件夹。

以“制作三组的朱世铮”为例，登录后应该看到：

- 收到任务通知：`收到 xx 导演的任务：xx 剧 / 第 x 集`
- 项目管理中出现云同步文件夹：`xx 剧`
- 文件夹中出现自己负责的剧集项目。
- 云素材库中能看到对应剧项目、剧集、镜头本、资产库。

组员可以：

- 打开自己负责的剧集。
- 查看剧本、镜头本、当前资产。
- 一键从镜头本创建画布节点或批量生产板。
- 在本地生成图片、视频、音频。
- 将生成结果加入个人收藏夹。
- 将结果上传到当前剧集资产库。
- 对上传资产做分类、命名、补充提示词。
- 点击“完成并通知导演”。

## 3. 完整业务流程

### 3.1 第一轮：剧本流转

1. 导演在云端管理后台创建剧项目。
2. 导演创建剧集。
3. 导演分配编剧。
4. 编剧登录写作台。
5. 写作台同步云端剧项目和剧集。
6. 编剧撰写剧本。
7. 编剧提交给导演。
8. 导演审核。
9. 导演要求修改或确认通过。

### 3.2 第二轮：视觉资产确定

1. 导演确认剧本后，开始确定视觉资产。
2. 视觉资产包括：
   - 角色
   - 场景
   - 道具
   - 风格参考图
   - 参考视频
   - 参考音频
3. 导演可以自己上传，也可以分发给组员补充。
4. 资产进入剧项目资产库，按分类管理。

### 3.3 第三轮：剧集制作

1. 编剧或导演把剧本拆成镜头本。
2. 镜头本进入云端剧集详情。
3. 导演把某一集或某些镜头分发给组员。
4. 组员收到任务通知。
5. 组员本地项目管理出现云同步文件夹和剧集项目。
6. 组员打开剧集，看到：
   - 左侧：剧本
   - 中间：镜头本
   - 右侧：资产库
7. 组员一键从镜头本创建画布节点或批量生产板。
8. 组员选择参数：
   - 生成类型：图片 / 视频 / 音频
   - 模型
   - 秒数
   - 分辨率
   - 比例
   - 每镜头生成数量
   - 是否自动加入本地收藏夹
   - 是否完成后等待人工上传
9. 系统弹出提示，说明：
   - 即将创建多少个节点或批量任务。
   - 会引用哪些云端镜头和资产。
   - 生成结果默认只保存在本地。
   - 需要手动上传后才进入云素材库。
10. 组员确认后，画布或批量生产板自动生成任务。

### 3.4 第四轮：上传、审核、同步

1. 组员生成完成。
2. 组员右键结果，选择“上传云素材库”。
3. 系统要求选择：
   - 剧项目
   - 剧集
   - 镜头
   - 分类
   - 素材名称
   - 提示词
   - 备注
4. 上传后素材进入该剧集资产库，状态为“未审核”。
5. 组员可以继续整理分类。
6. 组员点击“完成并通知导演”。
7. 导演在云端管理后台收到通知。
8. 导演打开对应剧集审核。
9. 审核通过后：
   - 单集状态更新为已完成或部分完成。
   - 所有有权限成员同步看到最新资产。
   - 云素材库中该集显示已完成。
10. 审核不通过时：
   - 资产标记为需修改。
   - 任务回到组员待办。
   - 组员收到修改通知。

## 4. 项目管理改造

### 4.1 本地文件夹类型

项目管理中的文件夹分两类：

| 类型 | 来源 | 是否可离线 | 说明 |
| --- | --- | --- | --- |
| 本地文件夹 | 用户本地创建 | 是 | 纯本地归档，不和云端绑定 |
| 云同步文件夹 | 云端剧项目同步 | 是 | 绑定云端剧项目，内容索引来自云端 |

### 4.2 文件夹字段

本地项目文件夹需要新增字段：

| 字段 | 说明 |
| --- | --- |
| `id` | 本地文件夹 ID |
| `name` | 显示名称 |
| `type` | `local` 或 `cloud_series` |
| `cloudProjectId` | 云端剧项目 ID |
| `teamId` | 团队 ID |
| `ownerUserId` | 当前本地归属用户 |
| `syncStatus` | `synced / pending / offline / conflict` |
| `lastSyncedAt` | 最近同步时间 |

### 4.3 剧集项目字段

本地项目需要新增云端绑定字段：

| 字段 | 说明 |
| --- | --- |
| `cloudProjectId` | 云端剧项目 ID |
| `cloudEpisodeId` | 云端剧集 ID |
| `cloudAssignmentId` | 云端任务 ID |
| `cloudRole` | 当前账号在该项目中的角色 |
| `syncStatus` | 同步状态 |
| `localOnly` | 是否仅本地存在 |

### 4.4 项目管理 UI 行为

项目管理顶部需要增加筛选：

- 全部
- 本地项目
- 云同步
- 我负责的
- 待提交
- 待修改
- 已完成

云同步文件夹卡片需要显示：

- 剧名
- 团队
- 当前负责集数
- 待处理任务数量
- 最近同步时间
- 云端状态

进入云同步文件夹后，每个剧集项目卡片显示：

- 集数
- 任务状态
- 导演
- 当前负责人
- 剧本状态
- 镜头本状态
- 资产状态
- 审核状态

## 5. 团队云素材库改造

### 5.1 总入口结构

团队云素材库不再按“全剧角色 / 场景 / 道具”作为顶层。

新的顶层是“剧项目”。

点击一个剧项目后，上方出现两个 Tab：

- 剧集
- 资产库

### 5.2 剧集 Tab

剧集 Tab 展示该剧全部剧集。

点击某一集进入单集详情，单集详情布局：

| 区域 | 内容 |
| --- | --- |
| 左侧 | 剧本 |
| 中间 | 镜头本 |
| 右侧 | 该集资产库 |

镜头本需要支持：

- 分镜列表。
- 每个分镜的文本描述。
- 图片提示词。
- 视频提示词。
- 音频提示词。
- 已绑定资产。
- 生成状态。
- 审核状态。
- 一键创建画布节点。
- 一键创建批量生产板。

### 5.3 资产库 Tab

资产库 Tab 是剧项目级资产库，不是单集资产库。

左侧是分类侧边栏，默认分类：

- 角色
- 场景
- 道具
- 参考图
- 参考视频
- 参考音频
- 风格参考

用户可以新增自定义分类。

每个分类中有资产卡片。

资产卡片字段：

| 字段 | 说明 |
| --- | --- |
| 名称 | 可编辑 |
| 类型 | 图片 / 视频 / 音频 / 文档 |
| 预览图 | 可拖拽 |
| 提示词 | 可复制、可修改 |
| 创建者 | 用户 |
| 来源 | 上传 / 生成 / 导演指定 / 收藏夹 |
| 审核状态 | 未审核 / 已通过 / 需修改 |
| 绑定范围 | 全剧 / 某集 / 某镜头 |

### 5.4 新增角色、场景、道具交互

以“角色”为例：

1. 用户点击角色分类。
2. 面板出现一个空白加号卡片。
3. 点击加号后，在加号下方展开一个类似批注的小表单。
4. 表单包含：
   - 上传角色图
   - 角色名
   - 提示词
   - 备注
5. 点击创建后，生成角色卡片。
6. 点击角色卡片可打开详情：
   - 大图预览
   - 名称
   - 提示词
   - 备注
   - 修改
   - 更新角色图
   - 删除
7. 拖拽角色图可以直接拖到：
   - 画布节点参考图区域
   - 批量生产板参考图区域
   - 单集镜头资产区域

场景、道具逻辑相同。

## 6. 收藏夹设计

收藏夹是个人云素材，不是团队资产库。

它和账号绑定，跟着用户走。

用途：

- 保存自己常用或刚生成好的图、视频、音频。
- 临时整理素材。
- 命名、分类、拖拽复用。
- 作为上传团队资产库的素材来源。

### 6.1 收藏夹结构

收藏夹支持文件夹。

字段：

| 字段 | 说明 |
| --- | --- |
| `favoriteFolderId` | 收藏夹文件夹 ID |
| `name` | 文件夹名称 |
| `ownerUserId` | 所属用户 |
| `parentId` | 父文件夹 |
| `sortOrder` | 排序 |

收藏夹素材字段：

| 字段 | 说明 |
| --- | --- |
| `favoriteAssetId` | 收藏素材 ID |
| `ownerUserId` | 所属用户 |
| `folderId` | 所属文件夹 |
| `name` | 素材名称，必须可编辑 |
| `type` | 图片 / 视频 / 音频 |
| `objectKey` | 云端对象存储 key |
| `thumbnailKey` | 缩略图 key |
| `prompt` | 原始提示词 |
| `model` | 生成模型 |
| `duration` | 生成时长，视频/音频适用 |
| `requestId` | 请求 ID |
| `taskId` | 任务 ID |
| `source` | 生成 / 本地上传 / 云素材复制 |
| `createdAt` | 创建时间 |

### 6.2 收藏夹和上传资产的关系

上传团队资产库时，素材来源有两种：

- 从收藏夹拖入。
- 从本地文件上传。

从收藏夹上传时，不一定要重复上传原文件；可以创建团队资产记录并复用对象存储中的 `objectKey`，但权限和归属要复制到团队资产表。

## 7. 生成结果回流

生成结果右键菜单新增：

- 添加到收藏夹
- 上传到云素材库
- 绑定到当前镜头
- 复制提示词
- 复制 Request ID
- 复制 task_id

点击“上传到云素材库”后打开上传面板。

上传面板需要自动带出：

- 当前账号
- 当前团队
- 当前剧项目
- 当前剧集
- 当前镜头
- 生成模型
- 提示词
- Request ID
- task_id
- 生成时长
- 输出尺寸

用户需要填写或确认：

- 素材名称
- 分类
- 是否绑定镜头
- 是否设为候选图 / 成片 / 参考素材
- 备注

上传后默认状态：

- `pending_review`

## 8. 一键创建节点 / 批量生产板

镜头本可以直接创建制作任务。

入口：

- 单集详情中间镜头本顶部：“一键创建”
- 每个镜头右侧：“创建节点”
- 每个镜头右侧：“加入批量生产板”

### 8.1 创建前参数面板

点击后一律弹出确认面板，不能直接创建。

参数：

| 参数 | 说明 |
| --- | --- |
| 创建目标 | 画布节点 / 批量生产板 |
| 生成类型 | 图片 / 视频 / 音频 |
| 选择镜头 | 全部 / 勾选镜头 |
| 模型 | 从模型配置读取 |
| 秒数 | 视频/音频 |
| 分辨率 | 720p / 1080p / 2K / 4K 等 |
| 比例 | 16:9 / 9:16 / 1:1 等 |
| 每镜头数量 | 批量数量 |
| 参考资产 | 自动带入 / 手动选择 |
| 输出处理 | 只本地保存 / 同时加入收藏夹 |

### 8.2 创建前提示

弹窗文案必须说明：

> 即将从云端镜头本创建制作任务。生成结果会先保存在本地，只有点击“上传云素材库”后才会同步到云端。请确认模型、秒数、分辨率和参考资产。

### 8.3 创建后的绑定

创建出来的节点或批量生产行必须携带：

| 字段 | 说明 |
| --- | --- |
| `cloudProjectId` | 剧项目 |
| `cloudEpisodeId` | 剧集 |
| `cloudShotId` | 镜头 |
| `cloudAssignmentId` | 任务 |
| `sourceScriptAssetId` | 剧本资产 |
| `sourceStoryboardId` | 镜头本 |

这样生成结果才能回传到正确位置。

- 本地缓存文件。
- 本地项目视图状态。
- 批量生产板临时状态。
- 尚未上传的生成结果。

### 11.3 冲突处理

冲突场景：

- 本地编辑剧本时，云端版本已经被导演修改。
- 本地镜头本生成任务还没完成，云端任务被取消。
- 本地素材还没上传，云端剧集已关闭。

处理方式：

- 明确提示冲突。
- 保留本地副本。
- 提供“覆盖云端 / 保存为本地副本 / 放弃本地更改”。
- 默认不自动覆盖云端。

## 13. 必须避免的误区

1. 不要把本地项目文件夹等同于云端文件夹。
2. 不要自动把所有生成结果上传云端。
3. 不要把收藏夹和团队资产库混在一起。
4. 不要让“全剧角色 / 场景 / 道具”继续做顶层入口。
5. 不要让镜头本一键创建任务时静默执行，必须先弹参数确认。
6. 不要只存临时下载 URL，云素材必须保存稳定 `objectKey / assetId`。
7. 不要让未审核素材直接同步成正式资产。

## 14. 推荐落地顺序

第一阶段：同步结构

2. 剧项目内增加剧集/资产库 Tab。
3. 单集详情三栏落地。

1. 镜头本一键创建画布节点。
2. 镜头本一键创建批量生产板。
3. 参数确认弹窗。
4. 节点和批量行写入云端绑定字段。

第四阶段：个人收藏夹

1. 收藏夹文件夹。
2. 收藏素材命名。
3. 生成结果加入收藏夹。
4. 收藏夹拖拽到上传面板。

第五阶段：上传与审核

1. 生成结果上传云素材库。
2. 未审核素材管理。
3. 完成通知导演。
4. 导演审核。
5. 审核结果同步。

### 17.11 推荐实施顺序

1. 先做 RBAC、审计日志、项目/剧集/任务/通知后端。
2. 再做项目管理云同步文件夹。
3. 再做团队云素材库“剧项目 → 剧集 / 资产库”改版。
4. 再做单集三栏和镜头本一键创建。
5. 再做收藏夹。
6. 再做生成结果上传云素材库。
7. 最后做导演审核闭环和完整 QA。

### 17.12 不做清单

以下内容明确不做：

- 不做隐藏账号。
- 不做不可发现的超级权限。
- 不在代码里写死账号密码。
- 不允许前端单独决定权限。
- 不允许未审核素材自动变成正式资产。
- 不允许生成结果静默自动上传云端。
- 不允许保存临时签名 URL 作为长期素材地址。
