# M2 权限矩阵

更新时间：2026-05-06

> 后端必须做真实权限拦截，前端只做按钮隐藏和提示。  
> 第一版角色不支持 owner 转让，因此 owner 不能退出自己创建的大组/小组。

## 角色定义

| 角色 | 英文 | 说明 |
| --- | --- | --- |
| 所有者 | `owner` | 创建者，拥有最高权限 |
| 管理员 | `admin` | 管理成员、审核申请、管理素材 |
| 成员 | `member` | 上传、查看、发送素材 |
| 只读 | `viewer` | 查看和下载素材 |

## 大组权限

| 操作 | owner | admin | member | viewer | 未加入 |
| --- | :---: | :---: | :---: | :---: | :---: |
| 创建大组 | 是 | 是 | 是 | 是 | 需登录 |
| 查看大组 | 是 | 是 | 是 | 是 | 否 |
| 查看大组邀请码 | 是 | 是 | 是 | 是 | 否 |
| 复制大组邀请码 | 是 | 是 | 是 | 是 | 否 |
| 通过邀请码申请加入 | 不适用 | 不适用 | 不适用 | 不适用 | 是 |
| 查看大组下小组 | 是 | 是 | 是 | 是 | 否 |
| 创建大组下小组 | 是 | 是 | 否 | 否 | 否 |
| 查看加入申请 | 是 | 是 | 否 | 否 | 否 |
| 审核加入申请 | 是 | 是 | 否 | 否 | 否 |
| 归档大组 | 是 | 否 | 否 | 否 | 否 |

说明：

- 大组归档/删除会同步隐藏其下小组。
- 大组删除是软删除，保留历史数据和审计日志。

## 小组 / 团队权限

| 操作 | owner | admin | member | viewer | 未加入 |
| --- | :---: | :---: | :---: | :---: | :---: |
| 创建独立团队 | 是 | 是 | 是 | 是 | 需登录 |
| 查看小组 | 是 | 是 | 是 | 是 | 否 |
| 查看小组邀请码 | 是 | 是 | 是 | 是 | 否 |
| 复制小组邀请码 | 是 | 是 | 是 | 是 | 否 |
| 通过邀请码加入 | 不适用 | 不适用 | 不适用 | 不适用 | 是 |

| 修改成员角色 | 是 | 否 | 否 | 否 | 否 |
| 移除 admin | 是 | 否 | 否 | 否 | 否 |

## 审计要求

以下操作必须写入 `audit_logs`：

- 创建、归档、删除大组。
- 创建、归档、删除小组。
- 修改成员角色、移除成员。
- 审核加入申请。
- 删除/归档素材。
- 发送、接收、拒绝素材。

## 后端权限判断原则

```text
JWT 验证
-> 获取 userId
-> 查询 organization_members 或 team_members
-> 判断 role
-> 放行或返回 403
```

前端不能作为权限边界。即使按钮被隐藏，用户手动请求 API 时后端也必须拦截。
