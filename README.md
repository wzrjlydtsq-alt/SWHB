# 星河智绘 (Xinghe Zhihui)

星河智绘是一款桌面端 AI 创作工作台，围绕可视化节点画布、影视分镜、图像/视频生成、本地项目管理和素材回流搭建完整创作流程。它适合把剧本、小说、角色设定、参考素材和多模型生成任务放在同一个工作区里统一编排，减少素材散落、提示词反复复制和项目状态难以追踪的问题。

## 核心能力

### 可视化节点画布

- 通过 React Flow 画布组织文本、角色、场景、分镜、图像生成、视频生成、导演台等节点。
- 支持节点连接、分组、批量布局、折叠分组、历史记录、画布快照和项目级导入导出。
- 生成节点支持提示词、模板、连接输入、参考图片、参考视频、参考音频、首尾帧、比例、分辨率、时长和批量生成配置。
- 支持项目级缓存和本地媒体协议，旧项目中的本地图片、视频、历史记录可以继续恢复和预览。

### AI 图像与视频生成

- 支持图生图、文生图、图生视频、参考视频、参考音频、首尾帧视频生成和全景生成等创作方式。
- 内置多模型配置入口，支持按模型维护独立 Base URL、API Key、比例、清晰度和高级参数。
- 生成任务由主进程队列统一调度，支持并发控制、轮询、取消、失败提示、历史写回和结果回流。
- 对旧网关、旧项目缓存、重复任务状态、视频缩略图、媒体预览和本地路径兼容做了多轮修复。

### 剧本、角色与分镜工作流

- 文本节点可导入剧本、小说或大段创意文本。
- 角色提取、场景提取、剧本分镜和导演节点可以把文本拆成可生成的镜头单元。
- 分镜结果可继续连接到图像/视频生成节点，减少从文字到画面的手工搬运。
- 生成结果可以回写到分镜素材候选，便于后续审核、筛选和复用。

### 3D 导演台

- 基于 Three.js 提供 3D 场景编排能力。
- 支持角色人偶、姿态、骨骼微调、场景道具、背景板、景别、构图、摄像机距离、方位、仰角、FOV 和跟拍模式。
- 可以把 3D 编排自动转成英文镜头提示词，并接入后续图像或视频生成节点。

### 工作区助手与本地文件能力

- 提供类似工程工作台的对话式入口，支持项目文件夹、工作区文件、任务记录、审查记录和最近素材。
- 支持粘贴、拖拽和导入图片、视频、音频、文本、Word、PDF、Excel 等附件，并生成有限长度的上下文摘要。
- 支持本地文件读写、目录索引、命令执行审批、浏览器检查、截图证据、DOM 检查和代码审查报告。
- 内置自动化模板和重试记录，可把常见检查、缓存巡检、生产队列检查等沉淀为可追踪任务。

### 素材库与协作入口

- 支持本地资产库、收藏夹、云端素材浏览、剧集/集数/镜头层级素材管理和素材拖拽到画布。
- 支持项目级缓存根目录、素材复制、缓存统计、路径恢复和历史素材复用。
- 提供团队、小组、成员、在线状态和画布观察入口，便于多人创作流程衔接。

### 桌面端稳定性

- Electron 主进程负责窗口、IPC、SQLite、生成队列、更新、诊断日志、媒体协议和上传清理。
- 渲染进程采用 React、Zustand、React Flow、Three.js 和分片状态管理。
- 针对旧项目迁移、缓存路径、视频 Range 播放、更新安装、文件选择器、设置弹窗、缩略图生成和崩溃诊断做了多版本修复。

## 目录概览

- `src/main`：Electron 主进程、IPC、数据库、任务队列、上传、更新和诊断。
- `src/preload`：安全桥接层。
- `src/renderer`：React 前端、画布、节点、工作区、素材库、设置和业务功能。
- `src/renderer/core/dag_engine`：节点工作流执行引擎。
- `src/renderer/services`：云端、模型 Provider、本地缓存和下载服务。
- `docs`：方案、接口、测试和迁移记录。
- `scripts`：发布、预检、迁移和 QA 脚本。
