# 星河智绘 (Xinghe Zhihui)

星河智绘是一款面向 AI 影像创作的桌面工作台。它把剧本、角色、场景、分镜、参考素材、图像生成、视频生成和项目资产管理放进同一个可视化画布中，让创作者可以从文本构思一路推进到可复用的镜头素材，而不必在多个网页、文件夹和表格之间反复搬运内容。

软件以 Electron + React 为基础，核心体验围绕“节点编排 + 本地项目 + 多模型生成 + 素材回流”展开。它适合剧集分镜、短片预演、角色设定、广告分镜、AI 视频批量试片和多模型创作流程管理。

## 核心功能

### 可视化节点画布

- 使用节点画布组织剧本、角色、场景、分镜、提示词、生成任务和素材结果。
- 支持节点连接、分组、批量布局、折叠分组、历史记录、画布快照和项目导入导出。
- 生成节点可接收上游文本、参考图、参考视频、参考音频、首尾帧、比例、分辨率、时长和批量参数。
- 旧项目中的本地图片、视频、历史记录和缓存路径可继续恢复，降低版本升级后的项目迁移成本。

### AI 图像与视频生成

- 支持文生图、图生图、图生视频、参考视频生成、参考音频生成、首尾帧生成和全景生成等流程。
- 支持按模型维护独立 Base URL、API Key、比例、清晰度和高级参数，方便在不同模型和网关之间切换。
- 生成任务由主进程队列统一调度，支持并发控制、轮询、取消、失败提示、历史写回和结果回流。
- 针对旧网关、重复任务状态、视频缩略图、媒体预览、本地路径和任务恢复做了多轮兼容处理。

### 剧本、角色与分镜流程

- 文本节点可导入剧本、小说、对白、角色小传或大段创意文本。
- 角色提取、场景提取、剧本分镜和导演节点可把文本拆成可执行的镜头单元。
- 分镜结果可继续连接到图像或视频生成节点，减少从文字到画面的手工整理。
- 生成结果可以回写为素材候选，便于审核、筛选、复用和后续镜头迭代。

### 3D 导演台

- 基于 Three.js 提供 3D 场景编排能力。
- 支持角色人偶、姿态、骨骼微调、场景道具、背景板、景别、构图、摄像机距离、方位、仰角、FOV 和跟拍模式。
- 可把 3D 编排结果自动转成镜头提示词，并接入后续图像或视频生成节点。

### 工作区助手

- 提供类似工程工作台的对话式入口，可读取项目文件、工作区素材、任务记录、审查记录和最近生成结果。
- 支持粘贴、拖拽和导入图片、视频、音频、文本、Word、PDF、Excel 等附件，并生成有限长度的上下文摘要。
- 支持本地文件读写、目录索引、命令执行审批、浏览器检查、截图证据、DOM 检查和代码审查报告。
- 内置自动化模板和重试记录，可把常见检查、缓存巡检、生产队列检查沉淀为可追踪任务。

### 素材库与项目资产

- 支持本地资产库、收藏夹、云端素材浏览、剧集/集数/镜头层级素材管理和素材拖拽到画布。
- 支持项目级缓存根目录、素材复制、缓存统计、路径恢复和历史素材复用。
- 支持团队、小组、成员、在线状态和画布观察入口，便于多人创作流程衔接。

### 桌面端基础能力

- Electron 主进程负责窗口、IPC、SQLite、任务队列、更新、诊断日志、媒体协议和上传清理。
- 渲染进程采用 React、Zustand、React Flow、Three.js 和分片状态管理。
- 针对旧项目迁移、缓存路径、视频 Range 播放、更新安装、文件选择器、设置弹窗、缩略图生成和崩溃诊断做了持续修复。

## 典型工作流

1. 导入剧本、小说或创意文本。
2. 提取角色、场景和分镜，整理成可执行镜头。
3. 在画布中连接参考素材、提示词和模型节点。
4. 批量生成图片或视频，并把结果回流到项目素材库。
5. 复用历史素材，继续迭代角色、镜头、分镜和成片素材。
